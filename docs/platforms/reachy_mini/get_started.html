🔧 Reachy Mini (Wireless) 設置指南

Reachy Mini (Wireless) 是自主版本，由 Raspberry Pi Compute Module 4 (CM4) 提供支持。它使用內部電池和 Wi-Fi 連接獨立運行。

1. 🔧 組裝

Reachy Mini 作為工具包提供。組裝是您旅程的第一步！

  • 所需時間： 2-3 小時
  • 工具： 盒子裡已包含所有工具
  • 說明： 強烈建議在查看手冊時同時查看在線指南或組裝視頻

💡 專業提示： 我們強烈建議在紙質手冊旁邊打開在線指南或組裝視頻。在線版本為每個步驟提供短視頻剪輯，使組裝更容易理解。

2. 🛜 首次啟動與 Wi-Fi 配置

組裝完成後，您需要將機器人連接到您的 Wi-Fi 網絡。

  1. 開機： 打開您的 Reachy Mini
  2. 下載 Reachy Mini Control： 如果您還沒有下載，請從官方網站下載並安裝 Reachy Mini Control 應用程式
  3. 運行應用程式： 打開 Reachy Mini Control 並點擊下方的「首次連接...」
  4. 按照說明操作： 應用程式將引導您完成連接過程。它會要求您連接到機器人的 Wi-Fi AP，然後配置您的 Wi-Fi

3. 🔄 更新系統

在繼續之前，強烈建議將您的機器人更新到最新版本。

  1. 使用 Reachy Mini Control 連接到您的機器人
  2. 連接後，點擊「⚙️」設定標籤
  3. 前往「系統更新」部分
  4. 安裝：如果有新版本可用，請按照螢幕上的說明進行安裝

4. 🕹️ 下一步：使用機器人

現在您的機器人已在線並是最新版本，您可以開始控制它！

👉 前往使用指南學習如何：

  • 使用 Reachy Mini Control
  • 安裝和運行應用程式（如對話或遊戲）
  • 使用 Python 編程您的 Reachy

5. 💻 進階：通過 SSH 直接連接到內部 Raspberry Pi

如果您需要通過 SSH 連接到 Reachy Mini 的內部 Raspberry Pi，憑證是：

username: pollen
password: root

連接後，您可以使用以下命令檢查 Raspberry Pi 和機器人設置的完整性：

reachyminios_check
