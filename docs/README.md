# Reachy Mini 文檔 - 繁體中文靜態版本

這是一個 Reachy Mini 機器人官方文檔的繁體中文靜態版本。

## 結構

```
docs/reachy_mini/
├── index.html              # 首頁
├── SDK/
│   ├── installation.html   # 安裝指南
│   ├── quickstart.html     # 快速入門
│   ├── python-sdk.html     # Python SDK 參考
│   ├── integration.html    # AI 整合
│   └── core-concept.html   # 核心概念
├── troubleshooting.html    # 疑難排解
└── README.md              # 此文件
```

## 如何使用

1. 開啟 `docs/reachy_mini/index.html` 在您的網頁瀏覽器中
2. 瀏覽各個頁面以了解 Reachy Mini 的使用方法
