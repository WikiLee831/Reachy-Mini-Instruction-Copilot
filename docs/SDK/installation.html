📦 安裝 Reachy Mini SDK

歡迎來到 Reachy Mini！本指南將幫助您安裝 Python SDK 和守護程序，開始控制您的機器人。

1. 📋 前置要求

安裝 Reachy Mini SDK 需要以下工具：

  • 🐍 Python： 3.10 - 3.12
  • 📂 Git： 最新版本
  • 📦 Git LFS： 最新版本

🐍 安裝 Python

我們使用 uv - 一個快速的 Python 套件管理器！

步驟 1：安裝 uv

在您的終端機中執行：

curl -LsSf https://astral.sh/uv/install.sh | sh

步驟 2：安裝 Python

在您的終端機中執行：

uv python install 3.12 --default

我們建議使用 Python 3.12，因為它是 Reachy Mini 支持的最新版本。

📂 安裝 Git 和 Git LFS

對於 Linux/macOS，在您的終端機中執行：

sudo apt install git git-lfs

最後，初始化 Git LFS：

git lfs install

2. 🏠 設置虛擬環境

💡 為什麼使用虛擬環境？ 它保持您的 Reachy Mini 安裝隔離，並防止與其他 Python 項目的衝突。現代 Python 開發需要這樣做！

創建環境

在您的終端機中執行：

uv venv reachy_mini_env --python 3.12

啟動環境

對於 Linux/macOS，執行：

source reachy_mini_env/bin/activate

✅ 成功指示： 您應該在命令行提示符的開始處看到 (reachy_mini_env)！

3. 🚀 安裝 Reachy Mini

選項 A：PyPI（推薦用於大多數用戶）

在您的終端機中執行：

uv pip install "reachy-mini"

如果您想使用模擬模式，需要添加 mujoco 額外功能：

uv pip install "reachy-mini[mujoco]"

🐧 Linux 用戶： 需要額外步驟來安裝 GStreamer。

🎉 恭喜！

您已成功安裝 Reachy Mini！您的機器人已準備好開始運行。
