📦 安裝指南

第一次使用命令列？🖥️

如果您是命令列新手，請點擊這裡

1. 📋 先決條件

🐍 安裝 Python

我們將使用 uv - 一個快速的 Python 套件管理員，讓安裝變得簡單！

步驟 1：安裝 uv

Linux / macOS

curl -LsSf https://astral.sh/uv/install.sh | sh

Windows

powershell -c "irm https://astral.sh/uv/install.sh | iex"

✅ 驗證安裝：

uv --version

步驟 2：安裝 Python

uv python install 3.12 --default

我們推薦 Python 3.12 作為 Reachy Mini 支援的最新版本。

📂 安裝 Git 和 Git LFS

Linux

sudo apt install git git-lfs

macOS

brew install git git-lfs

Windows

winget install --id Git.Git -e --source winget
winget install --id GitHub.GitLFS -e --source winget

✅ 完成安裝：

git lfs install
需求 版本 用途
🐍 Python 3.10 - 3.12 運行 Reachy Mini SDK
📂 Git 最新 下載原始碼和應用程式
📦 Git LFS 最新 下載模型資產

2. 🏠 設定虛擬環境

為什麼使用虛擬環境？它讓您的 Reachy Mini 安裝與其他 Python 專案隔離，並防止衝突。現代 Python 開發需要這個！

建立環境

uv venv reachy_mini_env --python 3.12

啟動環境

Linux / macOS

source reachy_mini_env/bin/activate

Windows

reachy_mini_env\Scripts\activate

✅ 成功指標：您應該在命令列提示的開頭看到 (reachy_mini_env)！

3. 🚀 安裝 Reachy Mini

選擇您的安裝方法：

📦 選項 A：PyPI 🔧 選項 B：來源

推薦給大多數使用者 - 只想控制您的機器人？這是給您的！

uv pip install "reachy-mini"

如果您想要使用模擬模式，您需要新增 mujoco 額外套件：

uv pip install "reachy-mini[mujoco]"

🐧 Linux 使用者：需要額外步驟

🎉 恭喜！

您已成功安裝 Reachy Mini！您的機器人已準備好活起來。
