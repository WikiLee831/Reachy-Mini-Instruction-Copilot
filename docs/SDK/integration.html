整合與應用程式

Reachy Mini 專為 AI 建置者設計。這是整合 LLM 和分享您的作品的方式。

建置應用程式

我們提供 CLI 工具來產生、檢查和發佈標準應用程式結構（與 Hugging Face Spaces 相容）。請參閱完整指南：建置與發佈應用程式。

JavaScript 網頁應用程式

想要零安裝、跨平台的應用程式在瀏覽器中運行？請查看 JavaScript SDK 與網頁應用程式 指南 - 建置靜態 Hugging Face Spaces，可以通過 WebRTC 從任何裝置（包括您的手機）控制您的機器人。

HTTP 與 WebSocket API

建置儀表板或非 Python 控制器？Daemon 通過 REST 公開完整控制。

  • 文件：http://localhost:8000/docs
  • 獲取狀態：GET /api/state/full
  • WebSocket：ws://localhost:8000/api/state/ws/full

AI 實驗提示

  • 對話示範：請查看我們的參考實作，結合 VAD（語音活動檢測）、LLM 和 TTS：reachy_mini_conversation_demo。
  • 自訂視訊/音訊管道：如果您的 AI 管道需要直接相機或麥克風存取（例如，自訂 OpenCV 檢測器、帶 sounddevice 的 Whisper），您可以使用 media_backend="no_media" 停用內建媒體管理器。請參閱 停用媒體 以獲取詳細資訊。
