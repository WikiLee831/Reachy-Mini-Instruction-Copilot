核心概念與架構

理解 Reachy Mini 在幕後的工作方式將幫助您建置強大的應用程式和除錯問題。

軟體架構

Reachy Mini 使用客戶端-伺服器架構：

  1. Daemon（伺服器）：
    • 在連接到機器人的電腦上運行（或模擬中）。
    • 處理硬體 I/O（USB/序列）、安全檢查和感測器讀取。
    • 公開 REST API（localhost:8000）和 WebSocket。
  2. SDK（客戶端）：
    • 您的 Python 程式碼（reachy_mini 套件）。
    • 通過網路連接到 Daemon。
    • 優點：您可以在強大的伺服器上運行您的 AI 程式碼，而 Daemon 在連接到機器人的 Raspberry Pi 上運行。

安全限制 ⚠️

Reachy Mini 有物理和軟體限制以防止自碰撞和損壞。SDK 將自動將值夾緊到最接近的有效位置。

組件 限制
頭部俯仰/滾動 [-40°, +40°]
頭部偏航 [-180°, +180°]
身體偏航 [-160°, +160°]
偏航差異 頭部和身體偏航之間的最大 65° 差異

馬達模式

您可以改變馬達的行為方式：

  • mini.enable_motors()：僵硬。保持位置。
  • mini.disable_motors()：鬆弛。無電源。
  • mini.enable_gravity_compensation()："軟" 模式。您可以用手移動頭部，它會停留在您離開的地方。（僅適用於 Placo 運動學後端。）
