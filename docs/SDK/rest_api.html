🔌 REST API 文檔

Reachy Mini 提供強大的 REST API，允許您從任何程式語言或平台控制機器人。

API 基礎

REST API 提供了對 Reachy Mini 所有功能的訪問，包括：

  • 🤖 機器人運動控制
  • 📷 相機和媒體流
  • 🎤 音訊捕捉和播放
  • ⚙️ 系統配置和狀態

認證

API 端點需要基本身份驗證。使用以下憑證：

  • 用戶名： pollen
  • 密碼： root

常見用例

1. 獲取機器人狀態

檢索機器人的當前狀態和位置信息。

2. 控制運動

發送運動命令到機器人的各個關節。

3. 多媒體流

訪問相機流和音訊數據。

集成示例

REST API 可以與任何支持 HTTP 的程式語言集成。常見的集成包括：

  • JavaScript / Node.js Web 應用程式
  • Python 腳本和應用程式
  • C# / .NET 應用程式
  • 移動應用程式（iOS / Android）
