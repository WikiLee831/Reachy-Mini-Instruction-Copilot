Python SDK 參考

💡 提醒：SDK 現在自動檢測是否應該通過 USB/localhost 或網路連接，所以 ReachyMini() 立即可用。您仍然可以在需要時強制模式：ReachyMini(connection_mode="localhost_only" | "network")。

移動

基本控制（goto_target）

平滑插值點之間。您可以同時控制 head、antennas 和 body_yaw。

from reachy_mini import ReachyMini
from reachy_mini.utils import create_head_pose
import numpy as np

with ReachyMini() as mini:
    # 同時移動一切
    mini.goto_target(
        head=create_head_pose(z=10, mm=True),    # 向上 10mm
        antennas=np.deg2rad([45, 45]),          # 天線向外
        body_yaw=np.deg2rad(30),              # 轉身
        duration=2.0,                      # 花費 2 秒
        method="minjerk"                  # 平滑加速度
    )

插值方法：linear、minjerk（預設）、ease_in_out、cartoon。

即時控制（set_target）

繞過插值。用於高頻率控制（例如，跟隨搖桿或產生的軌跡）。

感測器與媒體

相機 📷

相機的畫面可以按以下方式存取：

from reachy_mini import ReachyMini

with ReachyMini(media_backend="default") as mini:
    frame = mini.media.get_frame()

返回的畫面是形狀為 (height, width, 3) 的 numpy 陣列，資料型別為 uint8。

IMU 🧭

⚠️ IMU 僅適用於無線版本的 Reachy Mini

請查看 此範例

with ReachyMini() as mini:
    imu_data = mini.imu
    accel_x, accel_y, accel_z = imu_data["accelerometer"] # (m/s^2)
    gyro_x, gyro_y, gyro_z = imu_data["gyroscope"] # (rad/s)
    quat_w, quat_x, quat_y, quat_z = imu_data["quaternion"] # (w, x, y, z)
    temperature = imu_data["temperature"] # (°C)

音訊 🎙️ 🔊

音訊輸入（麥克風）和輸出（揚聲器）按以下方式處理：

from reachy_mini import ReachyMini
from scipy.signal import resample
import time

with ReachyMini(media_backend="default") as mini:
    # 初始化 - 在此之後，兩個音訊裝置（輸入/輸出）將被其他應用程式視為忙碌！
    mini.media.start_recording()
    mini.media.start_playing()

    # 錄音
    samples = mini.media.get_audio_sample()

    # 重新取樣（如果需要）
    samples = resample(samples, mini.media.get_output_audio_samplerate()*len(samples)/mini.media.get_input_audio_samplerate())

    # 播放
    mini.media.push_audio_sample(samples)
    time.sleep(len(samples) / mini.media.get_output_audio_samplerate())

    # 獲取到達方向
   # 0 弧度是左邊，π/2 弧度是前/後，π 弧度是右邊
    doa, is_speech_detected = mini.media.get_DoA()
    print(doa, is_speech_detected)

    # 釋放音訊裝置（輸入/輸出）
    mini.media.stop_recording()
    mini.media.stop_playing()

音訊資料格式：

  • get_audio_sample() 返回形狀為 (samples, 2) 的 numpy 陣列，資料型別為 float32，以 16kHz 取樣。
  • push_audio_sample() 期望形狀為 (samples, 1 or 2) 的 numpy 陣列，資料型別為 float32，以 16kHz 取樣。

⚠️ 注意：push_audio_sample() 是非阻塞的，意味著它立即返回而音訊在背景播放。如果您需要等待播放完成，請根據取樣長度和取樣率計算持續時間。

媒體後端選項

根據您的 Reachy Mini 版本和需求選擇適當的媒體後端：

  • media_backend="default" - 自動檢測最佳後端：當在與 daemon 相同機器上運行時為 LOCAL，遠端時為 WEBRTC（推薦給大多數使用者）。
  • media_backend="local" - 強制 LOCAL 後端（GStreamer IPC 相機 + GStreamer 音訊）。當在與 daemon 相同機器上運行時使用。
  • media_backend="webrtc" - 強制 WEBRTC 後端。Daemon 通過 WebRTC 將 H.264 視訊和 Opus 音訊串流到客戶端。
  • media_backend="no_media" - 停用媒體管理器並告訴 daemon 釋放相機和音訊硬體。當您需要通過 OpenCV、sounddevice 或任何其他外部程式庫直接存取時使用。當上下文管理器退出時，硬體會自動重新取得。

💡 提示：對於大多數設定，後端會根據您是本地還是遠端運行自動選擇。不需要指定 media_backend 值！

💡 提示：WebRTC 後端需要在客戶端機器上安裝 GStreamer。請參閱 GStreamer 安裝。目前只有 Linux 作為遠端客戶端完全支援。其他平台（Windows、macOS）將在 未來版本 中支援。

錄製移動

您可以通過移動機器人（順應模式）或發送命令來錄製動作，並儲存以供稍後重播。

from reachy_mini import ReachyMini
with ReachyMini() as mini:
    mini.start_recording()
    # ... 機器人移動 ...
    recorded_data = mini.stop_recording()
