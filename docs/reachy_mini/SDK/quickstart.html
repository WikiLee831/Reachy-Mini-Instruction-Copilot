快速入門指南

按照此指南讓您的 Reachy Mini 開始運作，無論是在真實硬體上還是模擬中。

1. 先決條件

請按照我們的 安裝指南 在您的電腦上安裝 Reachy Mini。

💡 重要：確保您已建立並啟動您的 Python 虛擬環境。每次開啟新終端機時都要記得啟動它！

🔧 在無線 Reachy Mini 上直接運行 SDK（可選）

2. 確保機器人伺服器正在運行（Daemon）

Daemon 是一個背景服務，用於處理與馬達和感測器的低階通訊。它必須運行才能讓您的程式碼運作。

  • 在 Reachy Mini（無線）上：當機器人通電時，daemon 會運行。確保您的電腦和 Reachy Mini 在同一個網路中。
  • 在 Reachy Mini Lite（USB）上 - 您有兩個選項：
    • 啟動 桌面應用程式
    • 開啟終端機並運行：reachy-mini-daemon
  • 對於模擬（無需機器人）- 您有兩個選項：
    • 啟動 桌面應用程式
    • 開啟終端機並運行：
      • Linux & Windows：reachy-mini-daemon --sim
      • macOS：mjpython -m reachy_mini.daemon.app.main --sim

⚠️ macOS 使用者：uv 在 macOS 上可能與 MuJoCo 有相容性問題。如果您遇到安裝或運行問題，建議使用 pip 直接代替 uv 處理 MuJoCo 相關套件。

如果您從 libgstpython 得到區段錯誤，請參閱 模擬疑難排解 部分。

✅ 驗證：在您的瀏覽器中開啟 http://localhost:8000/docs。如果您看到 Reachy SDK API 文件，您就可以開始了！

3. 您的第一個腳本

⚠️ 重要：保持 daemon 終端機開啟並運行！Daemon 必須保持活躍狀態，您的機器人才能運作。

建立您的 Python 腳本

步驟 1：開啟新的終端機視窗

步驟 2：建立一個名為 hello.py 的新檔案，並將以下程式碼複製貼上：

提示：建構函式現在自動檢測 Lite 與無線，並在 localhost 和網路之間切換。只有在進階情況下才覆寫它，例如 ReachyMini(connection_mode="network")。

from reachy_mini import ReachyMini

with ReachyMini() as mini:
    print("連接到 Reachy Mini！")
    
    # 擺動天線
    print("擺動天線...")
    mini.goto_target(antennas=[0.5, -0.5], duration=0.5)
    mini.goto_target(antennas=[-0.5, 0.5], duration=0.5)
    mini.goto_target(antennas=[0, 0], duration=0.5)
    
    print("完成！")

步驟 3：儲存檔案並運行您的腳本：

在新終端機中運行：

python hello.py

🎉 如果一切順利，您的機器人現在應該會擺動天線！
