🚀 開始使用 Reachy Mini SDK

快速預覽

只需幾行程式碼即可控制您的機器人：

from reachy_mini import ReachyMini
from reachy_mini.utils import create_head_pose

with ReachyMini() as mini:
    # 向上看並傾斜頭部
    mini.goto_target(
        head=create_head_pose(z=10, roll=15, degrees=True, mm=True),
        duration=1.0
    )

使用者指南

  • 安裝：5 分鐘設定您的電腦
  • 快速入門指南：在 Reachy Mini 上運行您的第一個行為
  • Python SDK：學習移動、看、說話和聽。
  • AI 整合：連接 LLM、建置應用程式，並發佈至 Hugging Face。
  • 建置與發佈應用程式：建立、測試、發佈和除錯 Reachy Mini 應用程式。
  • 核心概念：架構、座標系統和安全限制。
  • 教學：逐步學習 SDK 的實作 Jupyter 筆記本。
  • 📂 瀏覽範例資料夾

🛠 硬體概覽

Reachy Mini 機器人以套件形式銷售，通常需要 2 到 3 小時組裝。詳細的逐步指南可在上述特定平台資料夾中找到。

  • Reachy Mini（無線）：在板上運行（RPi CM4），自主，包含 IMU。查看規格
  • Reachy Mini Lite：在您的 PC 上運行，通過牆壁插座供電。查看規格
